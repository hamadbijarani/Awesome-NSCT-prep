# An 8-week NSCT study plan

Built for the ~8 weeks between late November 2026 and the tentative NSCT dates of **23–24 January 2027**. Adjust to your own semester load and confirm every date with your university's NSCT focal person.

## Ground rules

- **Weights first, weak areas second.** Problem Solving is 20%; the seven core areas are 10% each; OS and Cyber are 5% each. In 2026 the lowest national averages were OS (33.8), Networks (39.6), DSA (40.2) and Databases (42.3) — these are cheap marks if revised.
- **One bank for volume, one mock engine for timing.** Use [nsctprep.dev](https://nsctprep.dev) (or the local 2,170-MCQ bank) for topic practice and [nscttest.com](https://nscttest.com) / [nscttestpreparation.online](https://nscttestpreparation.online/) for full-length mocks.
- **Keep an error log.** For every wrong answer, write the topic, the rule, and why you got it wrong. Revisit it in weeks 7–8.
- **No official past papers exist.** Anything sold as one is fake. Practice from the [official competency list](https://nsct.hec.gov.pk/AreasOfCompetencies) ([PDF version](https://nsct.hec.gov.pk/Area%20of%20Competencies%20-%20National%20Skill%20Competency%20Test.pdf)).

## Week 1 — Diagnostic + Problem Solving

- Read the official competency list and note all **149 topics** (topic counts per area: PS 16, Programming 16, DSA 12, Databases 17, SE 16, Web 17, Networks 10, AI/ML 17, OS 12, Cyber 16).
- Take one timed baseline mock (100 Q / 120 min). Record per-area scores.
- Study Problem Solving daily: logic, patterns, number series, flowcharts, basic complexity, truth tables.
- Practice: 200+ easy/medium MCQs in Problem Solving; [HackerRank Algorithms](https://www.hackerrank.com/domains/algorithms); [LeetCode Easy](https://leetcode.com/problemset/?difficulty=EASY).

## Week 2 — Programming + DSA

- Programming: data types, control flow, functions, OOP, recursion, memory, code tracing (C++/Java/Python — pick the one you know best, but understand the others' syntax).
- DSA: arrays, linked lists, stacks, queues, trees, graphs, hashing, sorting/searching, Big-O.
- Practice: 150 MCQs per subject; [VisuAlgo](https://visualgo.net/en) for anything you cannot picture.

## Week 3 — Databases + Software Engineering

- Databases: ER/relational model, keys, normalisation to 3NF/BCNF, SQL joins, GROUP BY/HAVING, transactions/ACID, indexing, basic NoSQL.
- SE: SDLC models, Agile/Scrum, requirements, UML, testing levels, design patterns, Git, metrics.
- Practice: [SQLZoo](https://sqlzoo.net/wiki/SQL_Tutorial) + [LeetCode SQL](https://leetcode.com/problemset/?topicSlugs=database&difficulty=EASY) for hands-on SQL; topic MCQs for theory.

## Week 4 — Web Development + Networks & Cloud

- Web: HTML/CSS, JavaScript fundamentals, HTTP methods/status codes, REST APIs, cookies/sessions, basic security.
- Networks: OSI/TCP-IP, subnetting/CIDR, routing basics, DNS/HTTP, wireless, cloud models (IaaS/PaaS/SaaS).
- Practice: subnetting drills, 150 MCQs per subject.

## Week 5 — AI/ML + OS + Cyber Security

- AI/ML: supervised vs unsupervised, overfitting, evaluation metrics, basic neural nets, data cleaning, simple statistics.
- OS: processes/threads, CPU scheduling, synchronisation, deadlocks, paging/virtual memory, file systems — **highest-priority weak area**.
- Cyber: CIA triad, common attacks (SQLi, XSS, phishing), hashing vs encryption, authentication, OWASP basics.
- Practice: 150 MCQs each for AI and Cyber, 250 for OS.

## Week 6 — First mock block

- Two full 100-Q/120-min mocks this week, in a quiet room, on a screen (the real test is CBT).
- Spend the rest of the week **only on the error log**, re-testing the weak topics in the quiz builder.
- Re-read the 5% subjects' cheat sheets — quick marks.

## Week 7 — Mock block two

- Two or three full mocks. Target: finish in ~105 minutes with 10–15 minutes for review.
- Re-test every topic where accuracy is below ~70%.
- Use [flashcards](https://nsctprep.com/flashcards) and your own subject cheat sheets for spaced recall.

## Week 8 — Taper

- One final mock early in the week; no new topics after that.
- Light revision: cheat sheets, error log, subnetting/Complexity quick drills.
- Confirm registration, roll-number slip, centre, reporting time and ID requirements with your focal person.
- Sleep properly the night before. Attempt every question — no negative marking was reported in 2026, but confirm in the 2027 student guide.

## Weekly template

| Day | Focus |
|---|---|
| Mon–Fri | 60–90 min new/revision topic + 30–50 topic MCQs + error log |
| Sat | One subject quiz (timed) + review explanations |
| Sun | Rest or one full mock (weeks 1, 6–8) / light cheat-sheet review |
