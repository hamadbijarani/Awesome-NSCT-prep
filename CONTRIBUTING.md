# Contributing to Awesome NSCT Prep

Thanks for helping keep this list useful. The goal is **one trustworthy link per resource**, not the longest possible list.

## What belongs here

- NSCT-specific prep material: MCQ banks, mocks, syllabi, guides, videos, communities and open-source tools
- General CS/IT learning resources **only** when mapped to a specific NSCT subject in section 7
- Official HEC / VU / partner announcements and documents

## What does not belong

- Paid courses, "guaranteed pass" products, or anyone selling registration / past papers
- Affiliate links, referral links, or links behind a paywall (note freemium tools clearly)
- Duplicate mirrors of a resource already listed (mention them next to the original instead)
- Unverifiable claims about passing marks, exam dates or exam format

## Entry format

```markdown
- [Resource name](https://example.com) — one clear sentence on what it offers and who it helps. `[free]` `[english]` `[urdu]` `[open-source]` `[2027]`
```

For table sections, follow the existing columns. For new subjects in section 7, keep the **English / Urdu-Hindi / Practice** three-line pattern.

## Verification checklist (required before opening a PR)

1. Open the link — it must resolve without a login wall (unless the tool requires an account; say so).
2. Confirm the resource actually covers NSCT or the subject you claim.
3. Check whether it is a reupload/fork of an existing entry; if so, note that instead of adding a duplicate.
4. For date/format claims, link an official HEC/VU source. Mark anything else as *reported* or *unofficial*.
5. Test any MCQ answer spot-checked against your course notes.

## Common fixes

- Dead link → replace with a working URL or remove the entry.
- Stale 2026 dates → update to the current 2027 notice and keep the "tentative" qualifier.
- New repo/tool → add it under section 2 or 3 with a one-line description and licence/cost note.

## Pull requests

- One topic per PR, small and focused.
- Add a line to the "Contents" TOC when you add a new top-level section.
- Update the "last verified" badge in the README if you re-checked all links.
